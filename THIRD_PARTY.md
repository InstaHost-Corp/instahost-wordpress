# Third-party integrations

## WordPress MCP Adapter

- Project: <https://github.com/WordPress/mcp-adapter>
- Integration: required WordPress plugin; provides MCP transport, sessions, schemas, error handling, and Abilities API adaptation.
- Tested reference version: 0.6.1 (`23cb53e0b82f39238eec1c38cb055e28aa30fa7c`)
- Release artifact: <https://github.com/WordPress/mcp-adapter/releases/download/v0.6.1/mcp-adapter.zip>
- Release artifact SHA-256: `1c3cd47c32e99b4e7d8690a44a7890256e92a8b96f61776cbe1894e5483cf676`
- License: GPL-2.0-or-later

## Automattic MCP WordPress Remote

- Project: <https://github.com/Automattic/mcp-wordpress-remote>
- Integration: recommended client-side stdio proxy for connecting desktop MCP clients to the MCP Adapter HTTP endpoint.
- Tested reference version: 0.4.0 (`7190a4ccf9a16b909433133ecf90c52c9bb04da4`)
- License: MIT

No source code from either project is vendored into this repository.
